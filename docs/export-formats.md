# 匯出格式與功能 (Export Formats)

TYPO STUDIO 支援多種檔案輸出格式，不僅限於影像，還包括專案保存，滿足跨裝置與二次編輯的需求。相關實作皆位於 `vendor/app.jsx`。

## 支援的匯出格式

- **PNG**: 預設匯出格式，保留高畫質且支援無損壓縮。
- **JPG**: 支援以 JPG 格式匯出（預設品質設定為 `0.95`），適用於檔案大小受限的情境。

使用者可於介面中自由切換匯出的影像格式 (`exportFmt`)。

## 匯出功能分類

1. **單頁匯出 (`doExport`)**:
   - 允許匯出當前正在編輯的頁面。
   - 支援直接「複製到剪貼簿」(PNG 格式)，方便快速貼上到其他應用程式（如聊天軟體）。
   - 點擊「EXPORT」即可下載單張圖片檔案 (`.png` 或 `.jpg`)。

2. **整組匯出 (`doExportAll`)**:
   - 透過點擊「ALL」按鈕，可以一次匯出整組輪播的所有頁面。
   - 系統會自動將所有渲染好的頁面（PNG/JPG）與專案檔（JSON）打包成一個 `.zip` 壓縮檔進行下載。
   - 壓縮檔處理採用了輕量級的 `buildZip` 實作（採用無壓縮的 store method，因 PNG/JPG 已是壓縮格式）。

## 專案匯出與匯入

- **JSON 專案檔**:
  除了匯出圖片，使用者也能將專案的完整狀態匯出為 JSON 格式（`exportProject` 函式）。
- JSON 包含了所有頁面的設計資料與排版設定。此檔案能用來備份專案，或在其他裝置上「匯入」以繼續編輯。這在整組打包 (ZIP) 時也會自動包含在內 (`typo-project.json`)。
