# 渲染管線 (Rendering Pipeline)

TYPO STUDIO 使用自訂的自動排版引擎，統一處理預覽 (DOM) 與匯出 (Canvas) 的渲染邏輯。核心邏輯皆實作於 `vendor/app.jsx`。

## 文字處理與換行策略

排版引擎會分析文字內容並執行以下處理：

1. **中文避頭尾 (Kinsoku)**:
   透過 `applyKinsoku` 函式，確保標點符號（如 `。`、`，`、`！`）不會出現在行首，而開引號（如 `「`、`『`）不會被留在行尾。
2. **文字折行與平衡 (Text Wrapping & Balancing)**:
   - `wrapAllLines`: 處理多行文字的折行邏輯。
   - `balanceAtoms`: 實作類似 CSS `text-wrap: balance` 的效果，自動均衡多行標題的寬度，避免出現「上長下短」的不對稱排版。
3. **字級自動縮放**:
   系統會依據文字長度自動計算合適的字型大小 (`font-size` 與 `headSize` 計算)，確保標題填滿版面而不溢出。
4. **行距控制**:
   提供行距倍率設定 (`lineHScale`)，可在 0.8x 至 1.6x 之間調整，並在預覽與匯出時保持一致的視覺效果。

## Canvas 渲染匯出

最終的圖像輸出由 `renderToCanvas` 負責：
- 它會建立一個隱藏的 `<canvas>`，並依據指定的比例 (如 1:1, 4:5, 9:16) 與縮放倍率 (預設 3x，以達高解析度) 設定畫布尺寸。
- 在畫布上，所有在預覽時套用的排版規則、遮罩 (`bgOverlay`)、字型與陰影皆會被精確地重繪。
- 確保了所見即所得，你在螢幕上看到的預覽結果與最終下載的圖片一致。
